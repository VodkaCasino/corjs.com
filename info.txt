# О ПРОЕКТЕ "Kritikans-main"

## ОБЩАЯ ИНФОРМАЦИЯ
- **Тип проекта**: Unity игра (3D приключение/квест)
- **Версия Unity**: 6000.3.4f1
- **Язык разработки**: C# (основной), Python (дополнительный инструмент)
- **Платформа**: Windows

## ОПИСАНИЕ ИГРЫ
Это 3D игра в жанре приключения с элементами гоночного симулятора, где игрок управляет летающим персонажем на ховербайке. Игра включает:
- Управляемого летающего персонажа
- Гоночную трассу из колец
- Систему квестов и заданий
- Диалоговую систему с NPC
- Сбор коллектаблов (монеты)
- Различные миссии и испытания

## ОСНОВНЫЕ МЕХАНИКИ ИГРЫ
### Управление персонажем:
- Летание и передвижение в 3D пространстве
- Управление байком (ховербайком)
- Возможность взаимодействия с объектами
- Система свиста для подзова байка
- Пригибание для избежания препятствий
- Наклон при поворотах

### Камера:
- Камера с эффектом задержки (lag)
- Плавное следование за персонажем
- Ограничение вертикального поворота

### Квестовая система:
- 14 основных миссий + секретная миссия
- Автоматическое завершение активного квеста при начале нового
- Система целей (objectives) для каждого квеста
- Генерация трасс и колец для гонок

### Диалоговая система:
- Ветвящиеся диалоги
- Разные персонажи (NPC)
- Анимации во время разговоров
- Возможность повторения диалогов

### Коллектаблы и прогресс:
- Сбор монет по трассе
- Система подсчета собранных предметов
- Условия выполнения заданий
- Прокачки и улучшения

## ТЕХНИЧЕСКИЕ КОМПОНЕНТЫ

### Основные скрипты:
- **Controller.cs** - базовый класс для контроллеров
- **Quest.cs** - управление квестами
- **DialogController.cs** - система диалогов (в корне Assets)
- **CameraController.cs** - управление камерой
- **TrackGenerator.cs** - генерация трасс
- **RingsInstantiator.cs** - создание колец
- **FlyController.cs** - полёт на байке
- **MoveController.cs** - управление пешим движением
- **RotationController.cs** - управление поворотом (на байке)
- **NoActionsController.cs** - режим без управления
- **ControllerActivator.cs** / **ControllerActivatorSetter.cs** - переключение контроллеров
- **SaveLoad.cs** - сохранение при завершении миссии (NPC, деньги)
- **Interactable.cs** / **InteractableNpc**, **InteractableBike**, **InteractableWhistle** - взаимодействие с объектами
- **Poolable.cs**, **TransparentPoolable** - пулы для колец и коллектаблов

### Ассеты:
- 3D модели персонажей: MainChar (главный герой), Einstein, Pit, Morpheus, nuuton (Newton), tesla, Kamelot, Assetloader, Gruz, Happy, Scene, Inter, New2Bike (байк), Platforms
- Анимации (полёт, Duck, Whistle, Walk, диалоги, движения NPC)
- Звуки и музыка (164 аудиофайла, включая голосовые диалоги DialogQuest*)
- SkySeries Freebie - скайбоксы; RHOC - дополнительные ассеты
- Материалы и текстуры
- Префабы (кольца, квесты, NPC и др.)

### Внешние инструменты:
- **Python приложение для TTS** (Text-to-Speech)
  - Преобразование текста в речь с качественными голосами Microsoft Edge
  - Поддержка русского и английского языков
  - Категории голосов: Мужчина, Женщина, Ребенок, Мальчик, Девочка
  - Графический интерфейс на tkinter

## ОСОБЕННОСТИ ПРОЕКТА
- Активная разработка (последние изменения: январь-февраль 2026)
- Интеграция Python инструментов для генерации голоса
- Сложная система квестов с ветвящимися диалогами (cherrydev, DialogNodeBasedSystem)
- Физика полёта и управления байком (DOTween для анимаций)
- Множество персонажей и локаций
- Система сбора коллектаблов и прогресса
- Видео в начале и финальное после последнего квеста
- Байк уходит в гараж после PassedLastRing при касании платформы
- UI: I - управление/настройки, M - карта
- Система целей (IObjective): LastRingObjective, ColoredSquareObjective, WordsPlacingObjective, SwapObjectsObjective, TimedObjective, CargoObjective
- Коллектаблы: Money, Gear, Poolchik, KusokKoda, Balloon, CollectableIndex, CollectableInter, CollectableMap, ColoredSquare, JumpSound и др.
